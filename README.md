# ChainRotate

ChainRotate is a real-time data aggregator and event processor for decentralized networks and blockchain infrastructure management.

With ChainRotate, you get a lightweight tool that stays out of your way.

**What you get**

- ChainRotate is a real-time data
- aggregator and event processor for
- decentralized networks and blockchain infrastructure

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainRotate.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ChainRotate is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
